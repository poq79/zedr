# Z-EDR 管理台设计规格（DESIGN.md）

> 本文件是 UI-DESIGN.md（宪法）之下的**设计规格层**：把"对标 2026 顶级产品"翻译成
> 可执行的视觉决策。改任何页面前先读这里；本文件与实现不一致时，以提交时间为准更新。
> 规格来源：Eleken/Muzli 2026 登录页案例库、Anthropic frontend-design 四问、
> Hallmark 设计指纹方法论、Vercel/Linear 表面体系拆解。

## 1. 设计定位（四问）

| 问 | 答 |
|---|---|
| Purpose | SOC 值班 8-12h 的威胁可见性仪器：异常要跳出来，正常要绝对安静 |
| Tone | **仪器 × 编辑部**（Instrument × Editorial）：准、密、静；拒绝营销感 |
| Constraints | 离线零 CDN（系统字体）；无 CGO 单二进制；Tailwind v4 token；对比度 ≥4.5:1 实算 |
| Differentiation（记忆锚点） | ① **mono 数据字型**：一切数字/刻度/时间戳/版本号走 `--font-mono`；② **发丝线结构**：面板靠 1px 线分层，不靠阴影/渐变；③ **管线叙事**：五层检测流水线作为品牌视觉母题（登录页/空态复用） |

## 2. 表面体系（暗色默认 · v1.0 Carbon 重制）

> 2026-11-01 用户裁决：蓝色色调废弃推倒。新秩序对齐 shadcn.io 审美并按业务强化——
> **中性碳灰表面 + 近白主操作 + 语义色只表达威胁状态**；10 月业界趋势佐证：
> 中性暗灰（避纯黑）、极简+功能深度、单一强调色克制使用。

| 层 | 暗色 | 亮色 | 用途 |
|---|---|---|---|
| L0 背景 | `#0b0b0d` | `#f6f6f7` | 页面底 |
| L0-B 品牌面板 | `#08080a` + 白-alpha 网格纹理（仅登录左屏，双主题恒暗） | 同左 | 品牌叙事区 |
| L1 面板 | `#131316` + 1px 白-alpha.10 发丝线 | `#fff` + 黑-alpha.12 | 一切内容容器 |
| L2 浮层 | `#1a1a1d` + shadow-2xl | `#fff` | 菜单/弹窗（功能性深度，唯一允许阴影处） |
| 主操作 | **`--primary #fafafa`（近白）** | `#1b1b1e`（近黑） | 按钮/激活态不占用色相 |
| 语义 | 红 `#f87171`/`#dc2626` · 黄 `#fbbf24`/`#a16207` · 绿 `#34d399`/`#059669` · 严重 `#fb7185`/`#e11d48` | 同左 | SOC 色彩契约，唯一合法彩色 |
| 图表 | 普通条 `#a1a1aa`（中性），严重条用 crit | `#71717a` | 色彩只留给严重度 |

全部对比度实算值见 `index.css` 头注释（faint ≥4.9，语义色 ≥4.6）。

## 3. 字阶（双声部 · Geist）

| 角色 | 字体 | 字号/字重 | 用途 |
|---|---|---|---|
| 页题 | Geist Sans | 16.5px / 600 / tracking-tight | 页头 h1 |
| 页题副行 | Geist Sans | 11px / 400 / faint | 页头说明（真实信息，非口号） |
| 面板题 | Geist Sans | 11px / 600 / 大写间距 | CardTitle |
| 数据 | **Geist Mono** | 26-30px / 600 / tabular-nums | KPI、刻度、徽章数值、版本、时间戳 |
| 正文 | Geist Sans | 14px 基准 | 表格/表单/说明 |
| 组标签 | Geist Sans | 10px / 600 / tracking 1px / faint | 侧边栏分组标签 |

字体本地打包（`src/fonts/`，OFL 1.1，零 CDN）；**CJK 回退系统字**（YaHei/PingFang）——
打包中文子集成本过高，接受此取舍；Latin/数字承载字体身份。

## 4. 页面蓝图

### 4.1 登录页（分屏，对齐 Vercel/Linear auth 模式）

- **左屏 46%（≥1024px 显示）**：恒暗品牌面板。
  上：徽标+产品名；中：一句定位语 + **检测管线终端卡**（五层检测真实事实，
  mono 排版——"管线叙事"母题）；下：版本戳（mono）。
  纹理：44px 蓝图网格，透明度 ≤0.07，仅此一处允许。
- **右屏 54%**：表单面板。
  表单卡：登录框/密码框/CapsLock 提醒（维持）。
  卡下信息行（真实运维信息，非装饰）：
  服务端状态点（实时 `/health`：运行中·版本·uptime）｜忘记密码→`bin/resetadmin.exe`｜版权。
- 禁止：居中孤表单、光斑背景、发光 logo。

### 4.2 应用壳

- **侧边栏 220px**：导航按 IA 分组（总览 / 运营：告警·事件·报表·主机 / 策略：规则·白名单 /
  治理：审计·账号），组标签 10px faint；激活态 = brand-soft 底 + 2px 主色内嵌线（维持）。
- **页头 56px**：页题 + 副行（左）；实时通道·新鲜度·刷新·设置（右，维持）。
- 面板题统一 CardTitle；KPI 单带 + 发丝线分隔（v0.9.1 已立）。

## 5. 审计清单（Hallmark 式 pre-flight，提交前逐项过）

- [ ] 无新增渐变/毛玻璃/光斑/发光（浮层阴影除外）
- [ ] 一切新增数字为 mono+tabular
- [ ] 装饰必须承载信息；说出口就删
- [ ] 新文本色在其底色上 ≥4.5:1（记入 index.css 注释）
- [ ] 双主题各走查一遍；reduced-motion 降级生效
- [ ] 中文为主，英文只用于专有名词/缩写（EDR/MTTR/SOC）
